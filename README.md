# RPG Overworld 3 (em desenvolvimento)

A terceira etapa da minha jornada com RPGs em Python: levar o jogo
do terminal para uma **interface gráfica**.

A [V2](LINK) provou que a lógica do jogo funciona (combate por
turnos, zonas, chefes, save em SQLite). Agora o desafio é outro:
construir uma interface visual em cima dela usando **CustomTkinter**,
aprendendo na prática como separar lógica de jogo e apresentação.

## Objetivo

- Substituir os menus de terminal por telas, botões e campos de
  entrada
- Reaproveitar e refinar o que já existe na V2, em vez de recomeçar
  do zero
- Aprender sobre interfaces gráficas, eventos e organização de
  código em projetos maiores

## Status

* Em desenvolvimento. Por enquanto, a tela inicial e a entrada do
nome do personagem estão sendo construídas; o restante do jogo será
migrado por etapas.

## Sobre o projeto

Assim como as versões anteriores, é um projeto de aprendizado: cada
tela nova é uma desculpa para entender melhor Python, e os erros no
caminho fazem parte do processo.
